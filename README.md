# Sh.M Control

Open-source Windows desktop utility for system monitoring, gaming optimization,
network tools, and DNS management.

**Author:** Shayan Monavari  
**Website:** https://shayanmonavari.ir/  
**License:** MIT

## What's included

- Full application source (`shmcontrol/`, `main.py`)
- Resources and data files
- MIT license

Official installers (if any) are published only under **GitHub Releases** of this repository.

## Requirements

- Windows 10/11
- Python 3.12+

```bash
pip install -r requirements.txt
python main.py
```

## Trust

This repository contains the desktop client source so users can review the code.
No cloud backend source, API secrets, or bot tokens are included.
